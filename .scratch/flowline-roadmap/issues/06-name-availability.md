# Name availability

Type: research (AFK)
Status: resolved
Label: wayfinder:research

## Question

Is the name Flowline free on NuGet (the id and the `Flowline.` prefix) and GitHub, and does an existing software product use it? Which alternatives are clear?

Findings file: [docs/research/06-name-availability.md](../../../docs/research/06-name-availability.md)

## Answer

2026-11-11. Not legal advice. Detail and sources are in the findings file above.

- The NuGet id `Flowline` is taken by an active .NET tool (a Dataverse ALM command line tool for Dynamics 365 and Power Apps, version 0.21.0 published 2026-11-09), whose owner also publishes `Flowline.Attributes`. A `Flowline.*` package family would collide with it.
- A GitHub organisation named Flowline exists. PyPI and the Docker Hub account are taken. npm is free.
- Alternatives that looked clear on NuGet and GitHub: Flowgauge, Flowtally, Deliverylens, Flowcompass. Throughline, Leadline, Cyclelens, Paceline and Cadence are taken.

Still unverified: domains, NuGet prefix reservation, GitHub profile pages, and trademarks. No trademark register was queried; search summaries mention FLOWLINE registrations in software classes.
