# Flow metric definitions

Type: grilling (HITL)
Status: open
Blocked by: 05, 11
Label: wayfinder:grilling

## Question

What are the written definitions of cycle time, lead time, throughput, WIP and work item age for v0.1? Each needs definition, inputs, assumptions, edge cases (reopened items, skipped states, items moved between teams, removed items, items created in a done state), what would make it misleading, how to test it, and a worked example on a synthetic timeline. Results are percentile views, not averages.
